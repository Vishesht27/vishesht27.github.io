Research Work

Grouped Value Attention

An attention variant that caches grouped values and reconstructs content keys on demand via a learned linear map absorbed into the query, cutting persistent KV cache by ~45-47% versus GQA with near-GQA accuracy

Read Paper →

Grouped Query Experts

A mixture-of-experts layer on grouped-query attention that routes each token to a subset of query-head experts while keeping KV heads dense, matching GQA accuracy with half the query heads active and 1.7-1.8x faster long-context prefill

Read Paper →

Vision-Guided Chunking Is All You Need

A novel multimodal document chunking approach that leverages LMMs to process PDF documents in batches while maintaining semantic coherence and structural integrity

Read Paper →

Bahasa Harmony
